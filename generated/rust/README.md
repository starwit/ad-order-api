# Rust API client for ad-order-api

REST API for submitting and managing ride orders to a vehicle's autonomous driving (AD) stack, and for querying current vehicle status and component inventory. Runs within the vehicle's onboard network and serves exactly one vehicle. Onboard HMIs reach it directly; backend systems reach it via an API gateway which handles vehicle identification and routing.
